# 02 — Đối chiếu 15 chức năng Đệ Tốt

Trạng thái áp dụng cho toàn bộ yêu cầu của Đệ Tốt. **Có sẵn** dùng trực tiếp được về mặt năng lực. **Cần cấu hình** cần chọn provider, quyền hoặc chính sách. **Cần tích hợp** cần nối dịch vụ hoặc thành phần riêng. **Cần phát triển** cần bổ sung nghiệp vụ hoặc giao diện. Với chức năng còn thiếu, mã nguồn dẫn bên dưới là ranh giới tái sử dụng quan sát được. Các đánh giá thiếu tính năng cần xác nhận bằng cây nguồn đầy đủ.

| # | Chức năng | Trạng thái | Bằng chứng và phần việc |
|---|---|---|---|
| 1 | LLM Agent | Cần cấu hình | [agent.ts](https://github.com/openclaw/openclaw/blob/v2026.11.3/src/gateway/server-methods/agent.ts) và [agent-turn-service.ts](https://github.com/openclaw/openclaw/blob/v2026.11.3/src/gateway/agent-turn/agent-turn-service.ts). Dùng provider API key và model đã kiểm tra tool calling, reasoning, tiếng Việt. |
| 2 | Personal Memory | Cần cấu hình | [memory-core/index.ts](https://github.com/openclaw/openclaw/blob/v2026.11.3/extensions/memory-core/index.ts). Tách workspace, thiết lập truy hồi, phân loại dữ liệu và xác định quyền sửa/quên. |
| 3 | Daily Learning | Cần phát triển | [Memory Core](https://github.com/openclaw/openclaw/blob/v2026.11.3/extensions/memory-core/index.ts), [Dreaming](https://github.com/openclaw/openclaw/blob/v2026.11.3/docs/concepts/dreaming.md), [CronService](https://github.com/openclaw/openclaw/blob/v2026.11.3/src/cron/service.ts). Tận dụng củng cố bộ nhớ. Bổ sung nguồn opt-in, checkpoint, dedup, truy vết, duyệt ứng viên và thu hồi đồng ý. |
| 4 | Google Maps | Cần tích hợp | [MCP tại tag](https://github.com/openclaw/openclaw/blob/v2026.11.3/docs/tools/mcp.md) là điểm nối. [Places](https://developers.google.com/maps/documentation/places/web-service/overview) cho địa điểm, [Routes](https://developers.google.com/maps/documentation/routes) cho tuyến đường. Cần xác minh connector upstream khi có clone. |
| 5 | Google Weather | Cần tích hợp | [MCP tại tag](https://github.com/openclaw/openclaw/blob/v2026.11.3/docs/tools/mcp.md) là điểm nối cho [Google Weather API](https://developers.google.com/maps/documentation/weather/get-api-key). Chuẩn hóa vị trí, múi giờ, đơn vị và lỗi quota. |
| 6 | Google Calendar | Cần tích hợp | [skills/gog/SKILL.md](https://github.com/openclaw/openclaw/blob/v2026.11.3/skills/gog/SKILL.md) hướng dẫn CLI OAuth có đọc và ghi. Đề xuất connector hẹp qua [Calendar API](https://developers.google.com/workspace/calendar/api/auth), đọc trước, ghi sau khi duyệt. |
| 7 | Web UI riêng | Cần phát triển | [ui/package.json](https://github.com/openclaw/openclaw/blob/v2026.11.3/ui/package.json) cho thấy Control UI hiện có. Xây React cho chat, trạng thái job, memory và phê duyệt. |
| 8 | Web Agent | Cần cấu hình | [Manifest Playwright Core](https://github.com/openclaw/openclaw/blob/v2026.11.3/package.json), [browser plugin manifest trên main](https://github.com/openclaw/openclaw/blob/main/extensions/browser/openclaw.plugin.json), [Web search](https://docs.openclaw.ai/tools/web), [Browser](https://docs.openclaw.ai/browser). Bật provider search và browser profile cách ly theo nhu cầu. Manifest là bằng chứng dependency. Kiểm tra đường thực thi browser tại tag còn mở. |
| 9 | Computer Agent | Cần tích hợp | [Windows Hub src](https://github.com/openclaw/openclaw-windows-node/tree/main/src), [Nodes tại tag](https://github.com/openclaw/openclaw/blob/v2026.11.3/docs/nodes/index.md). Tận dụng pairing, capability và thao tác Windows đã cấp quyền. Cần xác minh thao tác UI theo phiên đăng nhập và chọn capability cho từng việc. |
| 10 | System Optimizer | Cần phát triển | [Windows Hub src](https://github.com/openclaw/openclaw-windows-node/tree/main/src) và [audit.ts](https://github.com/openclaw/openclaw/blob/v2026.11.3/src/security/audit.ts) là các điểm khảo sát về năng lực host và audit. Cần tiện ích riêng quét chỉ đọc, danh sách thư mục tạm, preview, cách ly và hoàn tác. |
| 11 | Device Registry | Cần phát triển | [devices.ts](https://github.com/openclaw/openclaw/blob/v2026.11.3/src/gateway/server-methods/devices.ts) có pairing, đổi tên và thu hồi token. Dùng device ID liên kết với IP quan sát, đường dẫn đã cấp quyền và lịch sử của Đệ Tốt. |
| 12 | Scheduler | Có sẵn | [src/cron/service.ts](https://github.com/openclaw/openclaw/blob/v2026.11.3/src/cron/service.ts), [cron RPC](https://github.com/openclaw/openclaw/blob/v2026.11.3/src/gateway/server-methods/cron.ts). Dùng một scheduler, chốt múi giờ và cách xử lý job lỡ lịch. |
| 13 | Voice AI | Cần tích hợp | [src/tts/tts.ts](https://github.com/openclaw/openclaw/blob/v2026.11.3/src/tts/tts.ts), [Windows Hub](https://docs.openclaw.ai/platforms/windows). Tận dụng TTS/Talk. Nối mic, STT, streaming, ngắt lời và kiểm thử tiếng Việt. |
| 14 | Chibi Pet | Cần phát triển | [Windows Hub src](https://github.com/openclaw/openclaw-windows-node/tree/main/src) làm tham chiếu cho companion/tray. Cần app desktop, đồ họa, animation và sự kiện có quyền tối thiểu. |
| 15 | Security & Backup | Cần tích hợp | [audit.ts](https://github.com/openclaw/openclaw/blob/v2026.11.3/src/security/audit.ts), [Backups tại tag](https://github.com/openclaw/openclaw/blob/v2026.11.3/docs/install/backups.md). Ghép chính sách ứng dụng, nhật ký và backup phối hợp của Gateway, Đệ Tốt và Windows Hub. |
